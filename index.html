📅 DAY1｜香港（完整白癡導航版）
✈️【香港機場入境】 1️⃣ 下飛機 → 跟著「Arrival」走 2️⃣ 看到 Immigration → 排隊入境 3️⃣ 出來後 → 找 Bus Terminal 標誌 4️⃣ 看到 S1 巴士牌 → 站在月台等
🚌【S1 → 東涌東薈城】 1️⃣ 上 S1 2️⃣ 坐到「東涌站 / Citygate Outlets」 3️⃣ 下車 → 看到 OUTLET 大樓 → 進去
🛍【東薈城】 - 直接進商場 - COACH / Nike / Adidas 自由逛 - 出來回巴士站
🚌【東薈城 → 葵興】 1️⃣ 找「E32 巴士站」 2️⃣ 坐到「葵興站」 3️⃣ 下車 → 找地鐵站入口
🏨【葵興 → 旭逸酒店】 1️⃣ 出站 → 找 7-11 2️⃣ 面對7-11 → 右轉直走 3️⃣ 一直走10–15分鐘 👉 看到酒店＝到
🍖【竺扶大班燒味】 1️⃣ 葵興 → 荃灣線 → 金鐘 2️⃣ 金鐘轉港島線 → 灣仔 3️⃣ A3出口 → 出來直走2分鐘 👉 看到排隊＝到
🚋【叮叮車】 1️⃣ 出餐廳 → 走到莊士敦道 2️⃣ 找電車軌道 3️⃣ 上車（往西） 4️⃣ 聽到「租庇利街」下車
🚶【半山手扶梯】 1️⃣ 下車 → 跟人流 2️⃣ 一直上坡 3️⃣ 看到長電扶梯＝到
🚡【山頂纜車】 1️⃣ 走到 IFC 2️⃣ 找「Garden Road」 3️⃣ 排隊＝山頂纜車站
🚢【天星小輪】 1️⃣ IFC → 下樓 2️⃣ 找海邊 3️⃣ 看到 Star Ferry → 上船（尖沙咀）
🍧【佳佳甜品】 1️⃣ 下船 → 面對鐘樓 2️⃣ 右轉廣東道 3️⃣ 一直走10–12分鐘 👉 看到招牌＝到
🍶【樂酒場】 1️⃣ 回彌敦道 2️⃣ 往佐敦方向走 3️⃣ 巷子內燈光酒場
